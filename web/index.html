SKEW — agent memory under concurrency

Every agent-memory system is benchmarked on recall. None is benchmarked on whether it stays correct when several agents write at once. This runs the same ingest logic three ways against one CockroachDB cluster and counts what breaks.

Identical code, identical database, identical workload. The only variable is transaction discipline. Correct behaviour is one active row per fact — every extra row is a memory the agent will later recall as if it were true.

Read-your-writes

The agent stores a memory, then immediately searches for it. On an eventually-consistent vector store this is the classic miss — the agent asks the user again. Here the row and its vector are one commit.
